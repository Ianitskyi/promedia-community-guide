# promedia-community-guide

«Як впорядкувати хаос. Посібник зі створення спільнот» — спецпроєкт
ГО «ПроМедіа» та Institute for War & Peace Reporting (IWPR).

Статична сторінка (`index.html`), стилі перенесено з `promedia.report`
(`css/style.css` — спільні токени кольору/шрифтів, `css/community-guide.css`
— компоненти цієї сторінки). Публікація через GitHub Pages
(`.github/workflows/deploy-pages.yml`, деплой з гілки `main`).

Оригінал посібника (PDF) — на сайті IWPR:
https://iwpr.net/global-voices/print-publications/how-bring-order-chaos
